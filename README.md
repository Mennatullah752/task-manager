# Task Manager App

A modern Task Management React application built with Vite, React 19, Tailwind CSS v4, and React Router v7.

## Features
- **Dashboard**: Task statistics overview (Total, Completed, Pending tasks)
- **Task Management**: Toggle completed status, delete tasks
- **Filter**: Filter by All, Active, and Completed tasks
- **Create Task**: Add new tasks with title and description
- **Task Details**: View specific task information via direct URL
- **Responsive Design**: Clean UI with Tailwind CSS

## Tech Stack
- React 19
- Vite
- React Router v7
- Tailwind CSS v4

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
